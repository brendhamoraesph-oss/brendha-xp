# Brendha xp

Portfólio de design de **Brendha Moraes** no formato de um computador dos anos 2000.

Um monitor CRT liga, carrega o "Brendha xp" e abre um desktop com pastas, janelas, menu Iniciar e o Brendha Player.

## Estrutura

- `index.html`: o site inteiro (HTML, CSS e JavaScript num arquivo só)
- `img/`: imagens dos projetos

## Publicar com GitHub Pages

1. Em **Settings → Pages**, escolha **Deploy from a branch**.
2. Selecione a branch `main` e a pasta `/ (root)`.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
